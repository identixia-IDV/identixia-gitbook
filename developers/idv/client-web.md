# Web demo

## Run locally

```bash
cd IDV/demo_clients/demos/web
npm install && npm run dev
# http://127.0.0.1:5175/
```

## Integration rule

Start verification through the [company backend](https://docs.identixia.com/idv/company-backend) (or your own server). Do not embed the company service bearer in the browser.
